How it works

Constellation reads an account’s public GitHub projects and draws each one as a star. There’s nothing to install and you don’t need an account.

Three steps

  1. 1

    Type a GitHub username

    Your browser asks GitHub for that account’s public projects: names, descriptions, main language, topics, stars and dates. A person or an organization both work. Want to look first? Try an example opens the sky above.

  2. 2

    Make it yours

    The map fills the screen and one panel holds four tabs: Look, Layout, Projects and Details. Every choice is a live preview of your own sky. Drag stars, feature your favourites, hide the rest, or press Shuffle for a surprise. Undo takes back anything.

  3. 3

    Get it

    Press Get it and choose where it goes:

    • Your GitHub profile, redrawn every day by a small GitHub Action.
    • An image as SVG or PNG.
    • A website, as one interactive page visitors can explore.
    • A link anyone can open.
    • A settings file to keep or move your design.

Why it’s there
Click any star. Its card explains each fact and says where it came from: From GitHub, Worked out by Constellation or Your choice.

A sky describes public data and your settings. It is not a score, and a bigger star is not a better project.

Signing in is optional

Any public account can be mapped without signing in. Signing in with GitHub adds your pinned projects, every language in each project, and your recent activity.

  • Constellation asks GitHub for read-only access and can’t change anything on your account.
  • A tiny sign-in service completes the GitHub handshake. It hands your browser a token and keeps nothing.
  • The token lives only in this tab’s memory. Reloading the page or pressing Sign out forgets it.
  • It never goes into links, images, downloads or settings files.
  • You can remove Constellation’s access at any time in your GitHub settings under Applications.

Under the hood

The layout engine is written in Rust and runs in your browser as WebAssembly. The same projects with the same settings always draw the same sky, so your profile picture doesn’t jump around from one day to the next. The picture itself is plain SVG, which stays sharp at any size and works in any README.

Constellation is free and open source. Developers can embed a sky with the <constellation-view> web component or use the command-line tool; the README explains both.
