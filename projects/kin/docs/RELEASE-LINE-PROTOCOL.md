# Release-Line Protocol

## `.0` Capability
Deliver the smallest complete end-to-end version.

## `.1` Correctness
Audit state transitions, validation, duplicates, retries, transactions, migration compatibility, stale commands, and authorization.

## `.2` Resilience & Accessibility
Audit offline behavior, restart/retry, stale tabs/devices, revocation, focus, keyboard, screen readers, reduced motion, narrow layouts, and denied permissions.

## `.3` Hardening & Polish
Audit resource bounds, malformed input, privacy leakage, performance, cross-browser behavior, documentation, terminology, and visual coherence.

## `.4+`
Only for real defects discovered after the normal incubation sequence.

## Tagging
Tags describe completed history. Never pre-tag a planned milestone.
