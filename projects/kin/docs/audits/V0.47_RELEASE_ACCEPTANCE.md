# v0.47 Release Acceptance Matrix

**Date:** 2026-10-16  
**Candidate:** v0.47.0 plus the stacked stabilization branches  
**Host:** Windows x64, Node 22.13.0, Rust 1.93.0

## Status language

- **PASS** means the stated command or interaction ran in the stated
  environment and passed.
- **PARTIAL** means automation exercises important mechanics but does not
  reproduce the requested real-world environment.
- **NOT RUN** means no qualifying evidence was produced. It is not a pass.

## PWA and recovery interpretation

Automated evidence is intentionally not promoted to a real-world pass. A fresh
profile is useful for storage and authority isolation, but it is not an
installed application, a second operating system, a real authenticator, another
person or another network. The physical matrix remains the release gate for
those claims.

## Release-readiness decision

- Automated Chromium/Edge evidence: **ready with the stacked fixes**, subject
  to the root GitHub workflow passing on the pushed head.
- Public multi-household deployment: **conditional**.
- Firefox/Safari, installed-PWA, physical-device, real-passkey, human
  fingerprint, separate-network and physical archive-transfer confidence:
  **insufficient evidence**.

No product architecture change is justified by the unavailable environments.
Complete the manual matrix on qualifying hardware and address only defects that
those runs reproduce.
