# Testing Kin before v1.0 — a guide for testers

Thanks for helping. Kin is a private app for coordinating a household: shared
to-dos and shopping, repeating tasks, notes, handoffs between people, and a
quick "what changed since I last looked". Everything you enter is encrypted on
your own devices before it's synced; the server only ever stores encrypted
data.

**Open:** <https://kin.journeytocode.io>

## Before you start

- **This is a test server.** Don't put anything real or private in it. It may
  be wiped, and v1.0 starts fresh.
- **You'll need** a recent Chrome, Edge, Safari or Firefox, and ideally a phone
  as well as a computer. A passkey (fingerprint, face or device PIN) makes
  unlocking easy.
- **On iPhone or iPad, install Kin first** (Share → Add to Home Screen, in
  Safari or in Chrome; keep "Open as Web App" on if you see it), then open it
  from the Home Screen and set up there. If you opened the link from inside
  another app, open it in Safari first.
  The Home Screen app keeps its own data, separate from the browser, so a
  household set up in the browser won't be in the app. Kin shows these steps
  on its first screen.
- **Save the recovery key** Kin shows you, somewhere like a password manager
  (tap Copy key and paste it there), and note its label
  (for example `K-7F3A`). It's the backup way into your household on that
  device. You don't have to type it back.
- Someone may give you an **invite code** to join their household instead of
  creating your own.

## What to try

Do whatever you'd naturally do, then try some of these:

1. Create a household (or join one with an invite) and turn on passkey unlock.
2. Add your phone as a second device, and compare the fingerprints on both
   screens when asked.
3. Add a few things: a to-do with a date, a shopping item, a repeating task, a
   note, a photo attached to an item.
4. Complete things on one device and watch them appear on the other.
5. Lock Kin and unlock it again.
6. Put your phone in airplane mode, add something, then turn the network back on.
7. Export a backup, and (if you're up for it) restore it in a different browser.

## What to tell us

Anything that made you hesitate counts, not just things that broke. For each
one, if you can:

- **What you were trying to do**
- **What you expected**
- **What actually happened** (a screenshot helps)
- **Device and browser** (for example "iPhone 15, Safari")

Send it to Mikey however is easiest. Please don't include your recovery key or
anything private in a report.

## Good to know

- If Kin shows an **update** prompt, accept it.
- If something says a **change couldn't be applied yet**, that's useful to
  report: tell us what you were doing on each device at the time.
- Passkeys are tied to this web address, so keep using
  `kin.journeytocode.io`.
- If your **passkey suddenly stops working** but your recovery key still
  unlocks Kin, the test server may have lost its data. Tell Mikey before you
  reset anything: it can usually be restored from a backup.
