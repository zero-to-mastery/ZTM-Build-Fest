# v0.27.0 — Household Playbooks

**Status:** Feature-branch implementation candidate; not tagged or published.

## Capability

- Create and edit up to 32 reusable templates, each with a title and 1–16
  ordered plain-text entries. Titles are bounded to 128 UTF-8 bytes and entries
  to 256 bytes. Archive is terminal and archived templates remain in history.
- Use a template under Routines to create a normal Need Item and ordered
  Checklist Steps. Generated records have stable IDs for retry and can be
  changed independently after creation; no ongoing link to the template exists.
- No nested templates, conditional steps, automation, marketplace, or generated
  plans.

## Compatibility

Protocol 19 adds canonical Playbook save/archive events (33–34) and a bounded
projection section. Protocols 1–18 remain readable for histories without
Playbooks and reject Playbook-bearing histories rather than omit data. The
existing encrypted event store and opaque sync relay carry the canonical bytes;
no server plaintext index or IndexedDB schema migration is introduced.

## Validation

Targeted Rust and real-WASM Playbook tests cover create/edit/archive, Unicode,
entry order, limits, replay, legacy Item history, duplicate delivery, and
same-time offline edits. Browser interaction has not been run without a local
browser executable.
