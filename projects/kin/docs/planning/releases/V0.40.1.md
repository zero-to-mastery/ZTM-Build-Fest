# v0.40.1 — Portable Membership Status Fidelity

**Candidate:** `kin-v0.40.1` on `kin-fast-track-v0.39-v0.40`. This is a correctness patch to the completed v0.39/v0.40 portability and restore batch. It does not reopen package architecture or change server access-control rules.

## Correction

Portable membership state now preserves explicitly removed Temporary members separately from naturally expired Temporary members across export and restore.

The server persists and exposes the authoritative `active`, `removed`, or `expired` membership status through the existing membership directory. Export serializes that status rather than inferring it from `memberActive` and `expiresAt`. Import normalization changes only an `active` Temporary member to `expired` when its absolute expiry has passed. A removed member stays removed as time passes.

The existing participation and trust checks still govern sync, key access, device authorization, and trust management. Portable membership remains descriptive archive data and does not grant authority.
