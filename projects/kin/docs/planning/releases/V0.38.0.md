# v0.38.0 — Modes & Member Context Polish

**Status:** Implemented candidate on `kin-fast-track-v0.36-v0.38`.

## Shipped behavior

- Household access settings group Adults, Limited Members, and Temporary Access. Active Temporary access displays the absolute end time; inactive Temporary entries remain marked as ended. The current identity model has no person-name field, so entries use member-type labels rather than inventing names.
- Adult-only invitation, recovery, device, membership-removal, and household-deletion controls are hidden from Limited and Temporary users. Server checks remain authoritative. Temporary access can be revoked by an Adult with the existing fresh-passkey member-removal flow.
- Responsibility assignment includes current active Adult and Limited Members plus eligible Temporary Members. The device directory carries each member's active state and expiry; expired/removed members are filtered from assignment selectors. Canonical inactivity convergence clears current responsibility after sync, while existing history remains attached to the household entity.
- Modes remain `Normal`, `Vacation`, `Guests`, and `Rest`. Mode changes affect routines; they do not change authorization, invite people, or revoke access. Guest mode does not create a Temporary Member. Temporary expiry/revocation remains authoritative in all modes.
- Handoff remains a shared household entity with no required sender/recipient pair. Multiple participants use the same canonical add/acknowledge/archive behavior. No presence or member-activity state is stored.
- Reminders remain explicit browser-local foreground notifications. No reminder is generated from another member's behavior. History remains entity-centric; no completion totals or contribution/fairness scores are added.
- Already-decrypted plaintext remains on disconnected devices; expiry blocks future requests and keys after reconnect.

## Accessibility and privacy review

- New Temporary expiry entry is a labeled native `datetime-local` control, announces validation through the existing alert region, and uses local time with a server-checked absolute timestamp.
- Adult actions include a target in their accessible name. The Temporary action names the member and temporary access.
- Membership UI adds no generated IDs; grouping uses semantic section headings and native controls. Existing app styles supply focus, dark mode, forced colors, reflow, zoom emulation, and reduced-motion behavior.
- Surveillance audit: no presence, last active, online status, read receipts, location, device location, activity stream, completion percentage, contribution score, fairness score, or behavior-monitoring notification was introduced.
