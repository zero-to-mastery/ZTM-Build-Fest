# v0.31.1 — Concurrent Maintenance Archive Correction

**Status:** Correctness patch candidate; no tag created.

When one device records maintenance while another archives the same Reference Record offline, the event is retained if the two facts have equal logical time and different device identities. Replay remains deterministic regardless of delivery order. A later maintenance event against an already archived Reference Record remains invalid.

The Rust regression test covers concurrent archive and maintenance creation plus rejection of post-archive creation.
