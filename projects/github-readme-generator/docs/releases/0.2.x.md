# v0.2.x Badge Studio release train

Each version is a distinct release commit. Prepare and merge the stacked release PRs in order; do not squash the train into one version. No v0.3 project-showcase or v0.4 banner work is included.

| Version | Scope                                                                             | Checkpoint validation                                                                                            |
| ------- | --------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| 0.2.0   | Advanced static Badge Studio, search/defaults/presets, picture pairs, insertion   | 181 unit tests, 44 Chromium browser tests, production build                                                      |
| 0.2.1   | Independent collections, starters, portable JSON, stack integration               | 187 unit tests, 45 Chromium browser tests, production build                                                      |
| 0.2.2   | Guided dynamic provider helpers, format checks and privacy docs                   | 213 unit tests, 46 Chromium browser tests, production build                                                      |
| 0.2.3   | Accessibility, contrast/clutter guidance, recovery, offline and browser hardening | 234 unit tests, 156 browser tests across Chromium/Firefox/WebKit, production build and root/subpath static smoke |

Every checkpoint updates package.json/package-lock.json, CHANGELOG and user documentation before the next version begins. Badge sources are ordinary Markdown/HTML. Tests mock remote responses and cannot establish live third-party availability. Contrast and clutter guidance are heuristics; automated keyboard tests do not constitute a full assistive-technology certification.

Validation exposed an intermittent queued dialog-close event affecting rapid GitHub lookup and a WebKit trigger-focus difference. Those shared focus fixes were carried back to the unpublished earlier checkpoints before preparing PRs. v0.2.3 adds in-place clipboard fallback. The final guide is [docs/badges.md](../badges.md).

Final production JavaScript: 378.02 KB (123.32 KB gzip); Health Worker: 59.12 KB. No new dependencies. A 150-badge collection is covered in all three engines, with at most twenty preview images. Existing 100/250 KB README smoke tests pass.
