# 1.9.22 — Accessibility and performance certification

This release records repeatable automated evidence for the already-shipped accessibility and large-document foundations in Epic 10, together with an explicit physical assistive-technology protocol.

- Edit, audit, import, export and publishing journeys have explicit keyboard, focus-return, label and status evidence. Remote publishing remains opt-in and review-gated; local editing and export remain available offline.
- Large-document evidence spans 100 KB through 1 MB pure analysis/diff/project round trips and measured 100/250 KB browser journeys. Health keeps one in-flight Worker job and only the latest pending source, terminates on removal, bounds displayed results and preserves exact source/autosave.
- Release branches and tags exercise branded Chrome, Playwright Chromium, Firefox and WebKit. Automated certification covers responsive 320 CSS-pixel reflow (equivalent to the layout viewport at 400% zoom on a 1280-pixel viewport), light/dark text and focus contrast, reduced motion, theme switching and source preservation. The manual protocol retains actual 200%/400% browser zoom because viewport equivalence does not exercise browser chrome or platform scaling.

The [assistive-technology acceptance record](../accessibility-acceptance.md) separates automated semantic/keyboard evidence from physical NVDA, Narrator and VoiceOver checks. This release does not claim WCAG conformance or a live screen-reader result from mocked/browser automation.
