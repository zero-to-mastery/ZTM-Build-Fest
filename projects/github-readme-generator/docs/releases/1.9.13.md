# README Studio 1.9.13

Cross-document link checks make a local documentation suite navigable before it leaves the workspace.

- Resolve relative links from each explicit workspace document path.
- Check target documents and their current GitHub-style heading or HTML anchors.
- Report missing, ambiguous, invalid and moved targets without fetching or rewriting anything.
- Review unresolved or truncated navigation before exporting the exact current Source anyway.

This release completes Story #87 and tasks #138 and #139.
