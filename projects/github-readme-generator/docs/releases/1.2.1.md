# v1.2.1 — Documentation Section Builders

Eighteen structured repository documentation sections are available in the builder Library. Installation captures package manager, install command, prerequisites and notes; Testing captures commands, test types and coverage notes. Environment Variables has explicit required flags, descriptions and example-placeholder rows with keyboard reorder/duplicate/remove controls.

The builders generate ordinary headings, lists, tables and fenced code, not a proprietary README format. They do not invent project facts, commands or license terms. Environment guidance explicitly discourages real credentials in both the form and generated output. Supported sections in new repository templates use these builders; older Custom Markdown and existing README source remain untouched.

See [documentation sections](../documentation-sections.md) for all fields, row limits, placeholders, portability and raw-edit behavior.
