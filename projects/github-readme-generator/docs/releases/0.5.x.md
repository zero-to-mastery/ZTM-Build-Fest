## Quality and limits

Browser checks cover keyboard/mobile library navigation, source preservation, copy fallback, offline widget configuration, broken previews, quota failure, pack portability, diff confirmation, undo/detachment, badge/widget reopening and 200 saved components. Existing large-README and project smoke tests remain in the full matrix. Automated tests do not certify assistive-technology accessibility or third-party availability.

Cards render in batches of 40 and never load remote previews while browsing. Remote widget previews are explicit. Generated badge images in the badge row editor contact their provider. No draft content is sent to a backend. Main JavaScript is 371.82 KB (112.48 KB gzip); the separately cached, statically imported highlighting chunk is 165.04 KB (54.87 KB gzip). The Health Worker is 79.43 KB. No dependency was added.

Structured ownership is local project metadata; exported READMEs contain ordinary Markdown/HTML. Cursor insertion remains raw. Manual source editing conservatively detaches ownership, with undo available; custom snippets always retain exact source. Unsupported preset versions retain their Markdown fallback. Existing arbitrary HTML is not automatically reverse-engineered. External widgets require upstream setup and may fail offline.
