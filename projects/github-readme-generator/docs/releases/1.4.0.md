# v1.4.0 — Writing Assistant

Optional selected-content AI assistance with all nine writing actions. Original, editable Proposed and an exact full-document Diff precede explicit Apply. No immediate replacement, background generation or AI dependency in core editing.

The configurable chat-completions adapter supports trusted remote or local endpoints, session-memory credentials, explicit content consent, bounded requests, cancellation and readable failures. Output stays inert during review; stale drafts are protected and Undo restores source/ownership. Manual proposals work without connecting a provider.

See [Writing Assistant](../writing-assistant.md) for setup, privacy, model compatibility and limits.
