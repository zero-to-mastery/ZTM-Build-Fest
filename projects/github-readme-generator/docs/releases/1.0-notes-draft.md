# README Studio 1.0 — draft release notes

**Unpublished draft. Do not tag or announce until the readiness gates pass.**

README Studio brings visual README authoring and direct Markdown editing into one local-first workspace. Ordinary Markdown/HTML remains the export format, without a proprietary runtime.

- Build badges and reusable collections, rich project showcases, themed sections and local light/dark SVG banners.
- Browse components, configure attributed widgets, save custom snippets and share portable packs.
- Import public GitHub data, review generated changes and preserve explicit edits when refreshing.
- Analyze structure and compatibility with the Rust/WASM core where available and JavaScript fallback; review diffs before applying safe refactors.
- Save portable Studio projects, retain reusable libraries in workspace backups and recover readable source from damaged metadata.
- Use an optional, separately deployed GitHub App service for explicit README, asset and workflow publishing with stale-write checks and partial-failure reporting.
- Navigate task groups and command search by keyboard, preview narrow layouts and continue core authoring offline after caching.

Read the [getting started guide](../getting-started.md), [privacy boundary](../privacy.md), [publishing setup](../github-publishing.md) and [known limitations](../known-limitations.md). Automated test results, manual acceptance and the production URL must be recorded in the final release evidence before publication.
