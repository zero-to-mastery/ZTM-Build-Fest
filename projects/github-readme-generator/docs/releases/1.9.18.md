# README Studio 1.9.18

Reusable visual tokens now have an explicit portable brand-kit contract.

- Save combined palette, component-style, deterministic banner-visual and optional safe logo-reference tokens as a brand kit.
- Edit and review allow-listed kit tokens, or rename, duplicate, delete, import and export kits in the bounded local preset editor.
- Export new kits and visual packs with explicit version-2 envelopes while migrating version-1 visual packs and legacy `readme-studio-visual-preset` files without lossy reinterpretation.
- Review every edited token before saving and explicitly copy a saved kit's reviewed logo markup without changing README Source.
- Preserve README Source, identity text, generated assets and explicit visual overrides; no operation publishes or transmits data.
- Reject unsafe or oversized logo references and stale/failed saves without overwriting the prior kit.
- Re-certify schema rejection/recovery, backup/restore, mobile keyboard use and offline reviewed application.

This release completes Story #94 and tasks #148 and #149.
