The preceding v0.3 PRs were merged into their prior release branches after the v0.2.3 integration landed, leaving main at 0.2.3. [Prerequisite PR #13](https://github.com/mnichols08/readme-studio/pull/13) integrates those existing v0.3.0–v0.3.3 checkpoints. Merge it first, then retarget each next release PR to main as its predecessor lands. Merging into an already-merged predecessor branch does not advance main. Do not squash away the individual version checkpoints.

Main JavaScript is 476.92 KB (150.96 KB gzip), CSS 27.89 KB (6.52 KB gzip), and the Health Worker 77.15 KB. No dependencies were added; Markdown parsing, sanitization, highlighting and existing catalogs remain notable contributors. Banner previews are debounced/cached; built-in gallery SVGs are cached for nine palettes and two modes. Unrelated Markdown edits do not regenerate banners.

Tests cover ordinary source export, unsafe XML/JSON input, theme ownership/reset, malformed libraries, save failure, portable packs, deterministic collisions, offline gallery application, 320px controls, and preview picture switching. Existing 100/250 KB README and 10/25/50-project smoke tests remain in the matrix. Tests mock remote providers and do not certify assistive-technology accessibility or third-party uptime.

Themes guide generated assets and builder settings; they cannot recolor GitHub. Table layouts can scroll on mobile. Downloaded banner assets must be committed manually. No CSS/runtime dependency, automatic upload, backend, authentication, AI, or remote SVG/font resource was introduced. See [themes](../themes.md), [banners](../banners.md), [section styling](../section-styling.md), and [architecture](../architecture.md).
