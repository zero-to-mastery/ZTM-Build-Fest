Tests use synthetic data. They do not make real repository writes. Crash recovery is bounded by the last successful persistence operation; abrupt OS/process termination can lose edits that have not yet been saved. No test result should be described as a guarantee against all data loss.

## Dependency and source review

2026-09-27: `npm audit --json` reported zero advisories across 146 installed dependencies; `cargo audit --file rust/readme-core/Cargo.lock` scanned 20 locked Rust dependencies with no findings. Five native Rust tests and formatting passed. No dependency upgrade was needed. All five direct production packages remain used: Markdown parsing, sanitization, syntax highlighting and two local font families.

The installed license inventory and full notices are in [THIRD_PARTY_NOTICES](../../THIRD_PARTY_NOTICES.md). CI branch names now enter the shell via environment variables, and release tags select the full browser matrix as well as release branches.

Mocked tests and local static smoke do not satisfy those gates. Record the deployment URL, tested commit, browser/assistive technology and repository used before marking stable acceptance complete.
