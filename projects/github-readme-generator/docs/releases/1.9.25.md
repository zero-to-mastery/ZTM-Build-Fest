# 1.9.25 — Audience-aware README review

Audience review adds four advisory reader perspectives, project-specific first-visit checks and a conservative information-hierarchy proposal. All analysis is local and read-only until an author reviews an exact diff and approves applying the proposed H2 order.

- Reader checks cite populated heading evidence and distinguish Observed, Not detected and Unknown. They do not produce a quality score or infer author skill.
- Game, CLI, library and API checklists name likely first-visit needs while leaving runtime verification Unknown.
- Section ordering moves exact source slices only when headings and recognized roles are distinct. Ambiguous structures are refused.
- Approval is invalidated by selection changes; stale drafts cannot receive an old plan. Apply creates one Undo checkpoint and does not publish.
- The lazy review is cached for offline first use. Unit and browser coverage exercises exact source preservation, refusal, stale state, 320px reflow and Chromium, Firefox and WebKit.
