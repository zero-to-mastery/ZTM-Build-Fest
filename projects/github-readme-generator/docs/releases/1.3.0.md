# v1.3.0 — Stack Intelligence

Opt-in manifest analysis now reads selected public repositories from README Audit. Results are labeled **Detected in selected repositories**, with manifest, ecosystem, dependency role and source evidence. No detection becomes a developer skill claim or changes a draft.

Initial root files: package.json, Cargo.toml, pyproject.toml, requirements.txt and go.mod. The framework supports Node, Rust, Python and Go declarations while documenting dynamic configuration, nested projects and unresolved dependency limitations.

Security boundary: GitHub-only text reads, no installs, no package scripts, no repository execution, no build tools and no package-URL following. Requests, file size, declaration counts, cache memory and rendering are bounded. Cancellation, fresh scans, partial failures and shared rate-limit cooldowns preserve clear result states.

See [Stack Intelligence](../stack-intelligence.md) for supported fields, privacy and limits. Verification is recorded before the release checkpoint.
