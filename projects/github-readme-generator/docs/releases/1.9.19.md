# README Studio 1.9.19

Accessible visual review is now part of the local banner workflow.

- Review missing, generic and meaningful banner alt text while editing.
- See light/dark primary, accent/title and muted-metadata contrast ratios against a conservative 4.5:1 target.
- Receive a concise assistive-technology status for the diagnostic that changed without rereading the full review on every edit.
- Keep incomplete color input safe and clearly marked as unavailable instead of receiving a misleading pass.
- Confirm that generated SVG banners are static and contain no animation or scripted motion.
- Honor both the operating system reduced-motion preference and the persistent Workspace Settings preference without changing README Source.
- Flag generic Markdown image labels in README Health while retaining the existing empty-alt check.

Automated release evidence covers pure accessibility diagnostics, exact source preservation, Chromium/Firefox/WebKit interaction, operating-system motion preference, persistent user preference after reload, production build and static smoke checks.

Manual review should still include keyboard navigation, a screen-reader pass over the live review region, visual inspection of every exported light/dark variant, and confirmation under both operating-system and in-app reduced-motion settings. Contrast output is an estimate, not WCAG certification.

This release completes Story #95 and tasks #150 and #151.
