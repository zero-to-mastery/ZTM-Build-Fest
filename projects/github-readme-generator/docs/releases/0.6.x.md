## Boundaries and limits

No dependency was added. GitHub data is public, fetched explicitly, normalized and escaped. Repository authoring reuses project import and badge providers. Suggestions are local and deterministic. Network Health is an advisory browser-side check with known CORS/HEAD limits, four concurrent requests, a 300-target cap and a five-minute cache. SVG error inspection is bounded and opportunistic. No result blocks export.

Generated ownership lives in Studio state only. Field comparisons protect manual project/profile values; section-level ownership is conservative where finer updates cannot be proven safe. Raw editing detaches ownership. Explicit recreation appends reviewed content, preserving manual Markdown. Up to 200 detached source records are retained. A refresh is one undo checkpoint and rejects stale draft reviews. Import version history and metadata freshness stay separate.

Tests mock network responses and exercise keyboard/mobile workflows, public-data failures, manual preservation, detached recreation, backup, undo, safe export, and large READMEs. Automated checks are not a complete assistive-technology audit or a guarantee of external service availability. See [GitHub-aware authoring](../github-aware.md), [refreshing](../refreshing.md), and [architecture](../architecture.md).
