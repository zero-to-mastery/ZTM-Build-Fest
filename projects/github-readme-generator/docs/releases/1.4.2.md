# v1.4.2 — Rewrite & Compare

Optional comparison mode generates independent Concise, Technical and Friendly versions from the same reviewed input/context. Desktop cards sit side by side; narrow screens stack them. Choosing a version stages editable Proposed, never the draft; applying still requires an exact diff and explicit approval.

Long-to-short, prose-to-bullets, bullets-to-paragraph and technical-notes-to-README-summary transformations work in single or comparison mode. Distinct prompts encourage different alternatives; identical output is flagged rather than disguised.

All three request messages are previewed, with notice of up to three provider charges. Sequential requests stop on failure or cancellation and retain completed work; no automatic retry. Input changes clear stale comparisons and consent. Grounding and context privacy remain unchanged.
