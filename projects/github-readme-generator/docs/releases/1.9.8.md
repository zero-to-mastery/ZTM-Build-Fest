# v1.9.8 — Round-trip regression matrix

Implements Story #79 and tasks #122/#123 under Epic #63. The Round-trip corpus now contains pinned raw Markdown and complete Studio-project JSON, including a mixed-ownership document with builder, exact Custom Markdown and component Blocks.

Each corpus file is SHA-256-pinned and must be listed in the manifest. The gate verifies exact Source, Block order and types, Seams, component-instance metadata, workspace preferences, Studio-project re-export and workspace-backup recovery. It also retains deterministic seeded single-range edit coverage. Project comparisons ignore only informational app/save values and regenerated identifiers; Markdown identity remains byte-for-byte.

`npm run test:round-trip` remains an early named CI step for pull requests, `main` and version tags. A fixture change requires an intentional hash update; a product change must preserve the existing corpus.

## Verification

- The focused Round-trip gate passed 22 pinned-corpus, golden-fixture and deterministic seeded-edit cases.
- The complete unit/server suite passed 1,297 tests across 73 files.
- The production build passed at 510.75 kB (155.04 kB gzip) for the main bundle; the 550 kB budget passed, and static smoke passed all six engine/base-path targets.
- The cross-browser matrix is required by CI before merge.

Round-trip checks are local and deterministic. They read checked-in fixtures, make no network requests and never modify user source or remote repositories.
