# README Studio 1.9.21

This release certifies the already-shipped optional Writing Assistant against Epic 09's evidence, provider and privacy contracts.

- Evidence-scoped prompts use only the reviewed Original, factual notes and explicitly selected context, instruct unsupported claims to be omitted, and keep imported content in data roles. A fail-safe local response check names those sources and flags every statement not found within one approved source, including paraphrases, contradictions and cross-source recombinations.
- Compatible and loopback-local adapters share a direct conformance matrix for bounded requests, complete text responses and rejection of malformed, partial or tool-bearing output.
- The exact destination, key policy and messages appear before consent; opening or configuring the tool sends nothing.
- Keys remain in tab memory and are excluded from drafts, backups and portable files. Provider or endpoint changes clear credentials and consent and cancel pending work. Explicit cancellation/close also clears the key, consent, factual notes, selected context and exact outbound preview.
- No-AI mode keeps manual Proposed → Diff → Apply available offline. Generation never changes README Source, and stale or cancelled results cannot apply.

Automated evidence uses mocked providers and covers pure prompt/context/request boundaries plus Chromium, Firefox and WebKit journeys for review, failure, cancellation, key cleanup and offline manual editing. It does not certify a paid provider, live model quality, provider retention or universal prompt-injection resistance.

Manual acceptance should inspect the destination and exact message preview, confirm no request occurs before consent, cancel an in-flight mocked request, switch providers and verify the key clears, apply a manually authored proposal by keyboard, undo it, and confirm README export remains ordinary Markdown.

This release completes Epic #70, stories #100–#102 and tasks #160–#165.
