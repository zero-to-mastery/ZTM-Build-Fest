# v1.4.3 — AI Safety & Provider Abstraction

Writing provider configuration is explicit and replaceable. Registered adapters own endpoint validation, key policy, request serialization and response parsing. The document model remains provider-independent. Choose a compatible endpoint, a key-free loopback server or no AI; the manual workflow stays available offline.

The dialog displays destination and transmission details, clears credentials and consent on provider changes, and preserves reviewed Apply. Imported repository content remains untrusted context. Hardened instructions reject embedded role escalation/exfiltration requests; tools and legacy function calls are rejected. The [safety audit](../ai-safety.md) records code boundaries and residual risks.

Project, single-draft JSON and workspace-backup exports share credential-field filtering. Keys used by the assistant remain tab memory only. User Markdown is not rewritten or scanned for secrets.
