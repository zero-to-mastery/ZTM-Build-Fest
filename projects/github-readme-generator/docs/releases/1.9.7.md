# v1.9.7 — Ownership conflict review

Implements Story #78 and tasks #120/#121 under Epic #63. A builder or component form can no longer overwrite source that changed or detached after the form opened. Ownership review presents the current Markdown as Original, the visual output as Proposed and a unified diff before any replacement.

Keep my Markdown is the focused default and the Escape outcome. Use visual version verifies the whole draft still matches the reviewed snapshot, replaces only the target Block while keeping its current Seam, clears only the Detachment record it used and creates one Undo checkpoint. If the draft changes during review, nothing is applied and the comparison refreshes first.

Restorable builder and component Detachments now advertise their saved visual version in the Sections list. Generated, shared, profile and banner ownership remains on its existing reviewed recreation paths. Non-Restorable or malformed records, missing targets and duplicate Block identities fail closed with the Markdown unchanged.
