# v1.2.2 — Project-Specific Documentation Builders

The Library now recommends documentation sections from a draft's repository template, with a manual, draft-specific project-type selector. Changing recommendations preserves Markdown and existing settings. npm/Python packages share Library recommendations; PWA uses Web App; all other builders remain available.

Specialized forms cover CLI syntax/flags/examples, API endpoint authentication/parameters/request/response, package imports/examples/API surface/compatibility, gameplay/controls/screenshots/save behavior, Cargo dependencies/features/Rust examples/registry links and web-app demos. Common setup, environment, architecture, testing and deployment builders remain reusable. Fresh templates choose these forms; saved content is not migrated or rewritten.

All output is ordinary Markdown. URLs are validated, screenshot alt text is required, rows use keyboard controls, and commands/examples stay literal. No registry requests, dependency versions, endpoint validity or project behavior are invented. See [project documentation](../project-documentation.md).
