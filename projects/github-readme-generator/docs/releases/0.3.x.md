# v0.3.x Project Showcase Studio release train

Each version was implemented, versioned, documented, tested, and committed before work began on the next version. Keep these four release checkpoints distinct.

| Version | Scope                                                                                                   | Checkpoint validation                                                                                                               |
| ------- | ------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| 0.3.0   | Rich manual project model, working-copy studio, highlights, technologies, links, screenshots and badges | 241 unit tests, 54 Chromium browser tests, production build                                                                         |
| 0.3.1   | Public repository selection/review, conservative mapping, refresh ownership, partial failures           | 249 unit tests, 56 Chromium browser tests, production build                                                                         |
| 0.3.2   | Pure layout serializers, presets, picture placement, mobile preview and project copy                    | 260 unit tests, 57 Chromium browser tests, production build                                                                         |
| 0.3.3   | Advisory Health, project packs, explicit link checks, bulk/search controls and deferred forms/media     | 275 unit tests, 189 browser tests across Chromium/Firefox/WebKit, production build, root/subpath static smoke and formatting checks |

The prior v0.2 PRs were merged into their preceding release branches, leaving `main` at v0.2.0 when this train was prepared. [Prerequisite PR #8](https://github.com/mnichols08/readme-studio/pull/8) brings the existing v0.2.1–v0.2.3 checkpoints to main. The project releases are stacked above that v0.2.3 baseline. Merge the prerequisite first, then retarget each next release PR to main before merging it in version order. Merging a later PR only into an already-merged predecessor branch does not advance main. Retain the individual release commits rather than squashing the entire train.

Release branches also run the full browser matrix and static smoke in CI. Tests mock GitHub/media responses; they do not prove third-party service availability or certify assistive-technology accessibility. Link checks classify browser/CORS restrictions as unverified, not broken. Health advice remains heuristic. Table layouts can scroll on narrow screens; the linear layouts remain available.

The final production main JavaScript is 425.04 KB (136.96 KB gzip), with a 72.53 KB Health Worker. No new dependencies were added. Project smoke tests cover 10, 25, and 50 entries; collapsed forms and screenshot sources are deferred. Existing 100/250 KB README tests pass across all three engines. See [the project guide](../projects.md) and [architecture](../architecture.md).
