# v1.3.3 — Stack-to-README

Detected repository evidence can now become reviewed technology badges, stack sections, package-manager guidance, install/test/build commands and package/crate links. Every suggestion starts unselected and displays its evidence and limitations. Users edit Markdown and approve an exact source diff before appending to the named draft.

Existing source, builder blocks and metadata are preserved. Changes invalidate approval; stale draft snapshots block application. Accepted changes participate in Undo/Redo and autosave. No script bodies are retained, commands executed or registry APIs contacted. Detection never means proficiency.

See [Stack-to-README](../stack-to-readme.md) for the workflow, privacy and inference boundaries.
