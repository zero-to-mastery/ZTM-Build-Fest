# v1.5.1 — Shared Components

Versioned shared Markdown definitions can be inserted into multiple workspace documents. Saving or deleting a definition never propagates source changes. Each insertion or update produces exact per-document source/diff previews and requires approval.

Locally edited copies are skipped; raw editing detaches shared ownership. Stale definition/document reviews are rejected before application. The whole reviewed result is persisted before document Stores change, and each document retains its own Undo/Redo checkpoint. Workspace backup/recovery carries definitions and links, with incoming collision remapping.

Six editable starting examples cover contributing, testing, security, sponsor/contact, badges and community links. See [Shared components](../shared-components.md) for the workflow, local-edit behavior and recovery limits.
