# v1.9.5 — Source-preserving structured edits

Implements story #77 (Source-preserving structured edits) with tasks #118 (source-range patch model) and #119 (golden Markdown round-trip fixtures), the first story of epic #63 (Lossless Editing and Ownership Recovery).

Typing or applying a reviewed Markdown change now alters only the **Edited scope**: the Blocks and Seams the edit actually touches. Every byte outside it remains identical, including CRLF and mixed line endings, a UTF-8 BOM, trailing whitespace, fenced code, raw HTML and the absence of a final newline. Builder, component, generated, shared, profile and banner Blocks outside the scope retain their visual ownership.

An Owned block touched by a raw edit becomes exact Custom Markdown and gains a visible, bounded **Detachment record**. The polite status message and Sections list name what detached without moving focus. Keyboard typing, changes in several distant ranges and moved-plus-edited sections use the same model. One Undo restores the complete prior draft.

Detachment records follow autosave, workspace backups and Studio projects but never exported Markdown. Portable files use explicit field allowlists and exclude earlier builder/component copies, labels and generated options no longer present in Markdown, removed generated/profile text, detached banner settings and generated banner assets. Public profile and repository data fetched from GitHub remains identifiable as fetched data. The verbatim storage-recovery download remains the documented exception.

The new named **Round-trip gate** pins seven byte-level fixtures by SHA-256, refuses unlisted Markdown, verifies exact Studio-project and workspace round trips, and runs deterministic seeded edit cases. It runs early in CI and remains part of the full unit suite.

See [Editing and Detachment](../editing.md#source-preserving-raw-edits), [Portable project schema](../project-schema.md), [Privacy](../privacy.md) and the [round-trip identity ADR](../adr/epic63-04-round-trip-identity-is-a-byte-level-ci-gate.md).
