# v1.2.0 — Repository README Builder

Repository READMEs now have a dedicated creation flow, available from Create and the template gallery. Twelve templates cover Web App, Library, CLI, API, npm Package, Rust Crate, Python Package, Game, Open Source, Tutorial, Documentation and Generic repositories.

Audit and queue Improve README actions, plus Improve next, open a suitable template using the audit's override or suggestion. Users review name, description, homepage, language, topics and template choice before creation. Existing source stays verbatim by default, optional sections are editable individually, and generated Markdown can be inspected first. Unknown instructions remain writing prompts. Open in Studio and Open existing README unchanged retain exact-source editing.

See [repository builder](../repository-builder.md) for source-preservation behavior, explicit fresh starts, metadata portability and template limitations.
