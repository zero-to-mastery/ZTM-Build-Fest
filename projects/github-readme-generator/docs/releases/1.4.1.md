# v1.4.1 — Context-Aware Writing

Seven explicit, editable context sources extend the optional Writing Assistant: GitHub profile, a selected public repository, project type, that repository's Stack DNA, project metadata, one selected section and writing style. Every source starts unchecked. Data comes from existing draft/session state; there is no automatic GitHub fetch or whole-workspace submission.

The exact system/user messages are displayed before sending. Context changes clear consent, cancel in-flight generation and invalidate proposal approval. Source limits reject oversized context without truncating it silently. Original / Proposed / Diff / Apply remains mandatory for generated changes.

Grounding instructions require factual support from supplied facts and omission of unsupported claims. Style is not evidence and detection is not proficiency. These are model instructions, not a guarantee of factual correctness; user review remains necessary.

See [Writing Assistant](../writing-assistant.md) for sources, request boundaries and limitations.
