# README Studio 1.9.17

Interrupted batch review now resumes through an explicit, local freshness review.

- Migrate older batch queues to a bounded, allowlisted progress journal.
- Save a content-free checkpoint after each successfully opened document, including partial runs.
- Classify recovered items against current exact local Source and target without making a request.
- Preserve changed and previously opened documents exactly; failed items remain pending for retry or skip.
- Keep all remote publishing separate and require its normal fresh review and approval. Recovery never replays it.

This release completes Story #91 and tasks #146 and #147.
