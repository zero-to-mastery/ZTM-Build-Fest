# v1.2.3 — Repository README Builder Hardening

Existing READMEs can be imported from UTF-8 files, pasted Markdown or the current draft. Conservative matching identifies headings, aliases and related topics with source lines. Empty and badge-only sections are advisory gaps; examples and comments do not become false section matches.

Merges preserve original source and append selected suggestions. Both merges and replacements require a fresh full-source/unified-diff review and explicit approval. Later edits invalidate that approval. Users can always open the imported source unchanged. All results are new local drafts; no remote write occurs.

The builder includes lazy sanitized light/dark previews at desktop, 768px and 320px widths, keyboard review focus and ordinary dialog dismissal. All twelve templates retain editable prompts rather than invented project instructions.

See [the repository builder guide](../repository-builder.md). Verification results are recorded before the release checkpoint.
