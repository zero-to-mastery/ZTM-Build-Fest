# README Studio 1.9.12

Documentation suites create a deliberately small set of related files without turning project-type guidance into a mandatory checklist.

- Choose a generic, CLI, API, library/package, game or web-app profile, then explicitly select only relevant files.
- Edit each file's generic starting Markdown and review every exact path and source before one whole-suite approval.
- Create the reviewed set atomically as local documents. Stale state, duplicate paths, limits, invalid content or failed storage leave the workspace unchanged.
- Keep creation offline and separate from publishing. No project facts are inferred and no GitHub request is made.

This release completes Story #86 and tasks #136 and #137.
