# 1.9.24 — Release confidence and local feedback

This release adds an auditable acceptance manifest, retained CI evidence metadata, a documented offline recovery drill and an explicitly opted-in local feedback export.

- The feedback report is created only after consent, reviewed before download, and never sent or persisted by Studio. It accepts no free text and includes only coarse count buckets and allowlisted answers, never Markdown, draft/repository names, URLs, credentials or browser identifiers.
- Release CI validates the acceptance matrix, binds its artifact to the commit/run and retains it without turning pending human gates into passes.
- Quota, unreadable storage, crash/reload, offline export and update-save refusal have named automated evidence in the recovery drill.
- Physical screen-reader and live GitHub App publishing remain manual gates. Mocked tests are explicitly insufficient and no completion is claimed until an operator records evidence.

Automated coverage includes focused diagnostic/redaction tests, update-save refusal, Chromium interaction and the existing multi-engine release suite. Existing Markdown, browser data and publishing approval boundaries are unchanged.
