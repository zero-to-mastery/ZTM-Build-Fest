# v1.5.0 — Multi-README Workspace

One local workspace now organizes profile, repository and unassigned README documents. The searchable Documents dialog and grouped quick switcher preserve independent source, target, builder state and session Undo/Redo. Target settings stay local and portable; publishing still requires remote review and confirmation.

Audit and attention-queue actions reopen a matching repository/branch/path document without overwriting local edits. Health follows the selected source and obsolete workers are terminated. Existing draft sources and recovery formats remain compatible.

See [Workspace documents](../workspace-documents.md) for target configuration, source backup, history memory limits and reload behavior.
