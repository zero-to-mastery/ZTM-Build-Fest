# 1.9.23 — Portable extension packs

This release completes Epic 11 with source-preserving pack compatibility, declarative extensions and an explicit import trust review.

- New snippet-pack exports use version 2. Version-1 files migrate in memory with exact reusable source, and future versions fail closed.
- Extension manifests contain ordinary component entries plus allowlisted inert capabilities. README Studio never imports or evaluates extension code and rejects executable fields, unsafe schemes and active markup.
- Review names provenance, publisher claims, capabilities and external URLs before confirmation. Import works offline, changes reusable local state atomically and leaves the current draft unchanged; rendering remote media remains an explicit action.
- The preview sanitizer and development toolchain use patched dependency releases; `npm audit` reported zero known vulnerabilities for the release checkpoint.
- Snippet-pack tooling loads on demand and preloads for offline use. The production main bundle is 539,351 bytes (163,816 gzip), within the existing 550 kB release budget.

See [Portable snippet packs](../snippet-packs.md), [Security boundaries](../security.md) and [ADR: Portable extensions are declarative data](../adr/epic11-01-portable-extensions-are-declarative-data.md).
