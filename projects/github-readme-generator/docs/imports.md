# Importing existing source

Use Import to paste Markdown, choose a local file, or fetch a public GitHub README. Review the source and import summary before applying. Empty documents, HTML-only source, code fences, BOM, Unicode and mixed line endings are valid source; preview normalization does not rewrite exports.

Choose a new draft when preserving your existing work matters. Splitting recognizes section boundaries but keeps source in Custom Markdown; it does not infer arbitrary visual form fields. Merge shows current/imported source and requires an explicit application. Undo restores the previous draft state.

Relative links need their repository and file context. A local file without that context may show unresolved images. Do not rewrite source merely to fix preview. Network failures distinguish missing repositories, rate limits, timeouts and offline conditions where available.

Portable project JSON uses **Open Studio project**, reusable packs use their relevant library import, and workspace backups use **Restore backup**. They are different formats. See [public formats](public-formats.md) and [project recovery](migrations.md).
