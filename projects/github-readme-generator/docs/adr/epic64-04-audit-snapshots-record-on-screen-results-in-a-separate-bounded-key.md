# Audit snapshots record on-screen results in a separate, bounded key and are compared conservatively

Implemented in v1.9.10.

Saving an Audit snapshot copies the results of audits the author already ran in this tab. It does not fetch, re-audit or poll. Nothing is captured on a schedule or as a side effect, so the feature cannot be mistaken for monitoring. A snapshot stores identities, not text: per Canonical repository the Observed revision, when it was read, README state, project type ID and whether that type was manual, whether history and links were checked, and the Audit finding identities. Unavailable link and image findings also keep their already-observed URL (at most 20 per repository) so a comparison can name them. README source, evidence prose and decisions are never stored. Snapshots record the audit and plan rule versions they were made under.

Snapshots live in their own key, `readme-studio:audit-snapshots:v1`. They are not workspace state because they describe an account's repositories rather than a document. That keeps them outside all-drafts backups, portable projects and README exports, as with Evidence Snapshots (ADR 0001) and Audit decisions (ADR epic64-02). Storage shares the origin quota with drafts, so the key is bounded. It keeps at most 5 snapshots per account and 20 in total, each snapshot holds at most 1,000 repositories with at most 60 findings per repository, and the whole key is at most 2,000,000 characters. Saving a sixth snapshot for an account removes that account's oldest one and says so. Exceeding the total or the size limit refuses the save and asks the author to delete snapshots, never evicting another account's data.

An Audit comparison reports a finding as added or resolved only when the repository was assessed in both snapshots, re-read in the later one, and kept the same project type and rule versions. A link finding is compared only when links were checked in both snapshots. Everything else is Unknown with its reason. We accepted that many differences show as Unknown in exchange for never reporting an improvement or regression that was not observed.
