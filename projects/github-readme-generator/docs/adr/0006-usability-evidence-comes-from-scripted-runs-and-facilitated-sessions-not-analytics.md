# Usability evidence comes from scripted runs and facilitated sessions, never in-app analytics

Measuring navigation complexity could have used in-app telemetry or an opt-in session recorder. Instead it uses two separate kinds of evidence. Scripted runs are Playwright executions of each Usability scenario with mocked network: they record completion and Step count as JSON test attachments, and fail when a scenario stops completing or exceeds its recorded step budget. Participant sessions are run by a facilitator from a written script, with notes entered by hand in the Friction tracker in the repository. The app gains no telemetry, session recorder or new storage, and Local activity keeps its existing fixed scope. We accepted slower, manual collection of human evidence in exchange for keeping the local-first privacy promise unchanged. Scripted runs and heuristic walkthroughs are always labelled as such and are never reported as participant results.
