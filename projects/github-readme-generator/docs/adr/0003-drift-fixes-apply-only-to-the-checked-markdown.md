# Drift fixes apply only to the exact Markdown that was checked

Reviewed drift remediation turns a Drift check result into line-level Fix proposals that the author approves one by one. Applying compares the current Source with the Source that was checked, as a whole string, and changes nothing if they differ in any way, or if the document or its target changed. We considered rebasing proposals onto later edits (re-finding each line by its text), but a moved or edited line could then receive a fix computed for different text, silently overwriting a manual edit. We accepted that any edit after the check means re-running it, in exchange for never applying a stale proposal and never touching text the author changed. Proposals live only in the open dialog and are discarded with the result (ADR 0002); applying is one Store edit with one Undo step and never publishes, so a GitHub write remains its own explicitly reviewed action.
