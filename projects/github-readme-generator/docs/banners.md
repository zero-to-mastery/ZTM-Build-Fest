# Local SVG banners

Banner Builder generates self-contained SVG locally. There are no remote fonts/images, scripts, foreignObject elements, AI calls, or upload requests. Fonts use the viewer's system sans-serif/monospace stack; exact font metrics vary by browser and GitHub's image renderer.

Enter a name, primary title, subtitle, website/handle, optional metadata line, and meaningful alt text. Suggest alt from name and title is editable. Text fields and dimensions are bounded. Width supports 320–1600px; height supports 120–600px. Profile Wide, Compact Header, Repository Header, and Custom sizes are available. Long text is fitted into the available width; very compact banners work best with fewer lines.

The live Accessibility review calls out missing or generic alt text and estimates primary, accent/title and muted-metadata text contrast against the selected light and dark backgrounds. It uses a conservative 4.5:1 text target. Screen readers receive a concise status for only the diagnostic that changed rather than a repeat of the complete review. The estimate is guidance, not WCAG certification: decoration, gradients, font size and the final GitHub rendering can affect readability, so inspect every exported variant. Accessibility guidance never edits README Source or blocks export beyond the existing requirement for valid, nonempty banner alt text.

Choose minimal, terminal, grid, constellation-inspired, gradient, geometric, code-lines, or monochrome decoration. A stable seed reproduces the same decorative geometry for the same configuration. Border/accent and alignment are optional. Palette defaults come from the active README theme; individual palette edits become explicit overrides. Use active theme palette resets those overrides. Changing a theme updates stored theme-owned banner palette values, not already-downloaded files.

Generate light, dark, or both variants. Preview light/dark at desktop or 320px width. Download SVG assets downloads the selected variants; individual file buttons are available if your browser limits multiple downloads. Download asset manifest saves a stable JSON inventory with validated paths, fingerprints and the exact picture markup; it does not contain SVG source or publish anything. Copy SVG source copies the previewed variant. Clipboard failures leave selectable source text. Save banner settings stores the configuration in the current draft without inserting content.

Generated SVG banners are static: they contain no animation, scripts or embedded remote media. README Studio honors the operating system's reduced-motion preference and the persistent Reduce motion option in Workspace Settings for its own interface and preview. External images you add separately may still animate and must be reviewed independently.

The default output is `banner-light.svg` and `banner-dark.svg` with a relative `assets/` path in picture markup. Edit the filename base and relative asset folder if needed. **Download these files and commit them to your profile repository.** Insert banner markup appends ordinary Markdown/HTML and saves the banner configuration as one undoable draft change. Local SVG previews work immediately; README image links work after you commit the assets. No automatic publishing or regeneration of committed files occurs.

Reusable banner presets save visual settings independently of the active draft. Use Save reusable banner preset in Banner Builder or Save banner preset in Visual presets. Brand kits pair those settings with a theme and may carry bounded light/dark logo URL or relative-path references plus alt text. Banner identity, title, subtitle, metadata, website, generated files and asset folders remain draft-specific. Apply reviewed presets preserves manually overridden visual fields unless you explicitly choose to reset them. Regenerate/download assets after changing the design; preset application never uploads or rewrites a repository asset.

SVG generation is debounced and cached by normalized settings in the editor. Preview width changes and unrelated Markdown keystrokes do not regenerate banner geometry. Gallery samples are cached by built-in theme and light/dark mode. Markup serialization only constructs safe asset paths and does not render SVG.
