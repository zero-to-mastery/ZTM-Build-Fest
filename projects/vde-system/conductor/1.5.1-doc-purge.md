# Documentation Purge & Re-forge: 1.5.1 Sovereign Baseline
<!-- @forge (Governance Plan) -->

## Background & Motivation
The VDE has achieved the 1.5.1 Sovereign Baseline, featuring absolute Zsh-native purity, the formalization of the Two Projects (Armor and Forge), and the strict enforcement of the Proof of Life Contract. However, the documentation across the repository, including the Sovereign Artifact Set and the core user guides, has fallen behind these massive architectural shifts. To maintain the "Use-Case Creed" and ensure Foundlings and Reinforcements are guided accurately, a total documentation purge and rewrite is required.

## Scope & Impact
This strike will touch every documentation file in the repository. We will completely replace outdated information with current 1.5.1 facts, mandates, and architecture.
The scope includes:
1. **Core Documents**: `README.md`, `docs/guides/getting-started.md`, `docs/development/contributing.md`, `docs/operations/installation.md`, `docs/governance/vde-protocol.md`.
2. **The Sovereign Artifact Set**: `docs/architecture/overview.md`, `docs/architecture/data-flow.md`, `docs/changelogs/current.md`, `docs/governance/vde-spec.md`, `USE_CASES.md`, `VDE_ANALYSIS.md`, `PROJECT_STATUS.md`, `docs/api/library-api.md`, `docs/governance/sovereign-charter.md`.
3. **The `docs/` Tree**: All remaining markdown files in the `docs/` directory.

## Proposed Solution
We will utilize the `generalist` sub-agent to perform bulk reads and rewrites. The sub-agent will process the files in logical batches to ensure context efficiency and accuracy.
Every rewritten file will:
- Reflect the 1.5.1 Sovereign Baseline.
- Detail the Unyielding Tetrad, the UAP, and the Proof of Life.
- Include the mandatory Architectural Tags (e.g., `<!-- @armor (Documentation) -->`) on Line 2 or 3.

## Implementation Plan

### Phase 1: Preparation
1. Create the Signet: `gh issue create --title "Documentation Purge: 1.5.1 Sovereign Baseline" --body "..."`
2. Create the branch: `git checkout -b forge/1.5.1-doc-purge develop`

### Phase 2: The Core & Artifact Set (Swarm Dispatch)
1. Dispatch `generalist` sub-agent to read and rewrite the **Core Documents** (`README.md`, `docs/guides/getting-started.md`, `docs/development/contributing.md`, `docs/operations/installation.md`, `docs/governance/vde-protocol.md`).
2. Dispatch `generalist` sub-agent to read and rewrite the **Sovereign Artifact Set** (excluding the core docs already handled).

### Phase 3: The Extended `docs/` Tree (Swarm Dispatch)
1. List all remaining files in `docs/`.
2. Dispatch `generalist` sub-agent to systematically update the remaining files, ensuring alignment with 1.5.1 and correct architectural tagging.

### Phase 4: Verification & Chronicle
1. Run `bin/vde-enforce-uap.zsh` to ensure no Ghost Zones or tag violations were introduced.
2. Run the `code-reviewer` agent to validate the documentation against the Rule Spine.
3. Present the final diff to the Clan Leader for the Pre-Merge Halt.
4. Submit the Chronicle (Pull Request).
