Identify specific teaching moments where one interaction would deepen understanding. Recommend a knowledge check for recall or conceptual discrimination, a runnable Rust example, a dependency-free HTML/CSS/JavaScript sandbox, or an example/challenge in a language explicitly enabled by the engine guide and request. For a challenge, name a bounded task, a visible TODO comment, an expected result, and an optional hint; do not invent hidden tests, grading, dependencies, multi-file projects, shell commands, or executable languages beyond the supplied allowlist. Explain why the exact source location and interaction type fit the learning outcome.
