# Drafting and Preview

## Draft-first authoring

Use drafts for iterative writing before publication. Draft state can be combined with scheduled dates for planned rollout.

## Preview fidelity

Admin preview is designed to match final published rendering, including theme styling and content formatting behavior.

## Recommended editing cycle

1. Create/open a draft in Admin.
2. Write body content in Markdown.
3. Configure metadata in settings panels.
4. Resolve readability/SEO guidance.
5. Re-check rendered output in preview.

## Common quality checks

- heading hierarchy consistency,
- image alt text completeness,
- link validity and clarity,
- metadata completeness (title/description/tags).

For Markdown specifics, use [Markdown Style Guide](../content/markdown-style-guide).
