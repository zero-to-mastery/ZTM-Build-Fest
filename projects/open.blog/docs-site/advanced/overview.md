This section covers the product areas that usually get missed in basic docs, but matter in real-world operation and long-term publishing.

- Publishing, portability, and cross-post syndication.
- Theme system and custom web components.
- Privacy-respecting analytics and backup patterns.
- Migration and import workflows.
- Technical architecture and crate boundaries.

- Maintainers operating production blogs.
- Teams running editorial and compliance workflows.
- Contributors extending core and theme behavior.
