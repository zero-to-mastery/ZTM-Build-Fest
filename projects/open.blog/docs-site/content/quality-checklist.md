# Content Quality Checklist

Use this checklist before publishing any technical document or post.

## Structure

- Clear title and scope.
- Logical heading hierarchy.
- Short, scannable paragraphs.

## Accuracy

- Commands validated locally.
- Paths and filenames verified.
- Version-sensitive notes called out.

## Accessibility

- Alt text on all instructional images.
- Link text is descriptive.
- Lists and tables are readable with screen readers.

## Publishing readiness

- `openblog check` passes.
- Preview reviewed in Admin.
- Date and draft status confirmed.
